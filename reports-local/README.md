# reports-local

Reports from skills run outside a PDLF step, one folder per skill family, named `{skill}-{topic}-{yyyy-mm-dd}.md`. Inside a PDLF step, a skill's output goes to the skill's own place and its copy to `pdlf-outputs\{step}\`, never here.

| Folder | Skills |
|---|---|
| `gstack\` | GStack |
| `matt-pocock\` | Matt Pocock |
| `opencode\` | OpenCode's own work: audits, reorganisations, registrations |
| `security\` | Sentinel, `security-audit-methodology`, `secure-software-engineering` |
| `archify\` | Archify and `mb-archify-scope` |
