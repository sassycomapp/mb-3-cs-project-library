# standard-operating-procedures-local

A standard operating procedure is the method determined for one specific task. It is recorded because it was purposely designed and is found nowhere else. This folder holds the procedures canonical to this business, one file each, `sop-{kebab-case-name}.md`. Procedures for every Mybizz project stay in `project-library-global\standard-operating-procedures-global\`.
