# pdlf-outputs

One folder per PDLF step, `a01` to `f46`. Each holds everything its step produced for this business, named `mb-3-cs-{step}-{run}-{name}`: the Step Receipt, the test evidence (`mb-3-cs-{step}-{run}-checks.xml` and each tool's report) and a copy of every output whose own place is elsewhere.
