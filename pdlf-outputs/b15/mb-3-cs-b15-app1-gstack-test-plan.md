## Affected Pages/Routes

## Key Interactions to Verify
- Booking flow: 3 server round trips; state preserved on back-navigation; timeout with retry preserves booking_flow_state
- Two customers confirming the same slot at once: exactly one booking, the loser offered nearest free slots
- The late-payment webhook against a new booking for the same slot: exactly one succeeds (D5 concurrency case, transactional reinstatement)
- The cookie banner: first visit sets no embedded-content cookie; Refuse all loads placeholders; Accept all loads embedded content; every choice and Load writes one consents row
- The acceptance box: unticked at booking, order, package purchase, online payment, portal sign-up and quote acceptance; the confirm button stays disabled
- The Vault: TOTP on every open, no remembered session; 5 wrong codes lock 15 minutes; every access emails the Owner
- Team Inbox: desk delivery to members and no one else; suppression honoured; Unassigned for unknown addresses
- Notifications: two identical sends at the same moment leave exactly one row; preferences and quiet hours honoured; App 5's push lands once in the feed; the bell badge matches the unread count (section 22 row 17)
- Sample data: no email, payment, reminder or export touches a sample record; Clear sample data removes exactly the recorded rows

## Edge Cases
- Existing contact books again — no duplicate contact
- Provider unavailable / no free resource — clear message, alternative offered
- Payment declined, then retried; hold expires unpaid — slot and resource freed
- Duplicate webhook deliveries (same event_id) — processed once; forged signature — HTTP 400, no row
- A summary task run twice for the same period — exactly one row per period with the recalculated figures (section 22 row 18)
- Contact deduplication conflict — existing contact updated, not rejected
- Server call timeout mid-flow — no partial record, flow state preserved
- Boundary values: pricing models, package balance (0 remaining), place limit full, payment terms 0 and maximum
- Midnight, month-end and daylight-saving boundaries on every schedule
- Voice tier 4 given a full sentence with missing fields — form partly filled, nothing saved before confirmation
