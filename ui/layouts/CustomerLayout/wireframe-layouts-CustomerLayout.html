Section 1 — Introduction

To the developer: This wireframe indicates which components to place on the CustomerLayout and how to configure them.

Conventions:

  • Solid border = visible on load. Dashed border = hidden on load (visible = False).
  • Each component displays: component_name (Type) "fixed text if set at design time".
  • The native NavigationRailLayout handles the app bar and sidebar automatically. Navigation items use m3.NavigationLink components.
  • On mobile, the rail collapses to a bottom navigation bar automatically.
