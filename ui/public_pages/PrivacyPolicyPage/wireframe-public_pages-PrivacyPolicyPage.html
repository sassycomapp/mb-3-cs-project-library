PrivacyPolicyPage

Public-facing page rendering clauses from privacy_policy table via ClauseBuilder data model

Section 1 — Introduction

To the developer: This wireframe indicates which components to place on the PrivacyPolicyPage. This is a public-facing read-only page that renders privacy policy clauses from the privacy_policy table. Clauses are grouped by category and ordered by sort_order. Only active clauses (is_active = True) are displayed. Clause data is managed via ClauseBuilder in Settings (PolicyEditorForm).

Conventions: Solid border = visible on load. Dashed border = hidden on load. Each component shows: component_name (Type) "fixed text"

Section 3 — Properties

Designer-Only Properties
None — all component properties can be set programmatically. Clause content is rendered dynamically from the privacy_policy table. Only active clauses (is_active = True) are displayed. Clauses are grouped by category and ordered by sort_order within each category.
