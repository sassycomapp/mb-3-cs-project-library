Wireframe: VideoDisplayComponent

Package: components/ [Phase 4]

Purpose: Shared display-only video embed component used on BlogPostForm and HomePage. Programmatically hidden when no valid video URL exists.

Source of authority: DESIGN.md VideoDisplayComponent section, scaffold-spec.md

Section 1 — Introduction

To the developer: This wireframe indicates which components to place on the VideoDisplayComponent and how to configure them.

Conventions:

  • Solid border = visible on load. Dashed border = hidden on load (visible = False).
  • Each component displays: component_name (Type) "fixed text if set at design time".
  • This is a display-only component. Input controls belong in host forms.
  • V1 supports YouTube only.
