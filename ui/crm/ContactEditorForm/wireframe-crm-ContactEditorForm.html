Section 1 — Introduction

To the developer: This wireframe indicates which components to place on the ContactEditorForm and how to configure them.

Conventions:

  • Solid border = visible on load. Dashed border = hidden on load (visible = False).
  • Each component displays: component_name (Type) "fixed text if set at design time".
  • Role is set programmatically in code (per ADR-43), not in the Designer Properties Panel.
