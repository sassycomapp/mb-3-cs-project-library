# adr-local

Decisions that belong to this business only, one file each, `adr-{kebab-case-name}.md`, in the format of the `domain-modeling` skill's `ADR-FORMAT.md`. A deviation from a global standard is recorded here with its business-domain reason.

Global decisions stay in `C:\dev\project-library-global\adr-global\` and are referenced, never copied.
