Implementation Notes

VideoDisplayComponent is a shared custom component used in BlogPostForm and HomePage.
Supports multi-source video: YouTube, Vimeo, and other embeddable sources.
Uses 16:9 aspect ratio container with responsive sizing.
The video section is hidden automatically when no URL is configured (business_profile.home_video_url or blog_posts.video_url).
Input controls for video source and URL belong in the host forms (BlogEditorForm, ServiceEditorForm, SettingsForm).
See ADR-034 for platform constraints on media handling.
Properties table
None — video URL and source are set programmatically from the host form.
