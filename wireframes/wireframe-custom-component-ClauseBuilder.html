Behaviour Notes

Component Behaviour
1. Category Selection: When the Owner selects a category from dd_category, the RepeatingPanels filter to show only clauses in that category.

2. Seeded Clauses: Clauses from the master template (is_seeded = True) are displayed with a green left border. The Owner can edit their text but cannot delete them.

3. Custom Clauses: Clauses added by the Owner (is_seeded = False) are displayed with a blue left border. The Owner can edit and delete them.

4. Add Custom Clause: Clicking "+ Add Custom Clause" reveals the add form. The Owner enters a title and body text, then clicks "Add Clause" to create the clause.

5. Edit Clause: Clicking "Edit" on any clause reveals the edit form pre-populated with the clause title and body. The Owner makes changes and clicks "Save Changes".

6. Save: Clicking "Save" writes all changes to the appropriate datatable (privacy_policy or t_and_c) and publishes the updated content to the public-facing policy page.

7. Document Type Parameter: The component accepts a document_type parameter ("privacy_policy" or "t_and_c") that determines which datatable to read from and write to.
