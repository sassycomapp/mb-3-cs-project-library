LandingPage

Public landing page — renders one of three template variants based on landing_pages.template_type

Structure

col_landing_page (ColumnPanel)

Template Variant: Lead Capture

col_lead_capture (ColumnPanel) — visible when template_type = "lead_capture"
[ LeadCaptureTemplate — hero + lead capture form + trust badges ]
col_lead_capture (ColumnPanel) layout variant, built into LandingPage — hero section, email/name form, trust badges, thank-you state

Template Variant: Event Registration

col_event_registration (ColumnPanel) — visible when template_type = "event_registration"
[ EventRegistrationTemplate — event details + registration form ]
col_event_registration (ColumnPanel) layout variant — event details, date/time, registration form, confirmation state

Template Variant: VSL (Video Sales Letter)

col_vsl (ColumnPanel) — visible when template_type = "vsl"
[ VslTemplate — video embed + CTA + lead capture ]
col_vsl (ColumnPanel) layout variant — video player, CTA button, optional lead form
col_footer (ColumnPanel)
FooterComponent (Custom Component) from components/FooterComponent

Properties

Designer-Only Properties
None — template selection driven by landing_pages.template_type field. Layout variants are content panels inside this form, not standalone components. One panel visible at a time based on template_type.

Architecture

Data source: landing_pages table (authoritative-schema.md §5.3)
Template types: "lead_capture", "event_registration", "vsl"
Layout variants: Built INTO LandingPage form (not separate components) per scaffold-spec.md v2
Routing: /landing/:slug via Anvil Routing dependency
Lead capture: Creates both leads and contacts simultaneously (ADR-004)
Analytics: views_count, conversions_count tracked in landing_pages table
User flow: §13 Lead Capture via Landing Page
