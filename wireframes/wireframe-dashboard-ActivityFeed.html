Implementation Notes

ActivityFeed is a dashboard-specific subcomponent, not a shared custom component.
Belongs to `dashboard/components/` package.
Used in DashboardForm.
Activity items are sourced from the `activity_log` table.
Icon and color vary by action_type: booking (purple), payment (green), contact (light purple), campaign (yellow).
Responsive: single-column layout on all screen sizes.
Properties table
None — all component properties can be set programmatically in code.
