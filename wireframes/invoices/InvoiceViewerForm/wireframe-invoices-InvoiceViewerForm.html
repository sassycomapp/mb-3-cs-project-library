Wireframe: InvoiceViewerForm

Package: invoices/ [Phase 2]

Purpose: Read-only detail view of a single invoice. Displays all architecturally defined invoice fields with status-appropriate action buttons.

Source of authority: scaffold-spec.md, DESIGN.md InvoiceViewerForm Completeness section, globals-contract.md

Section 1 — Introduction

To the developer: This wireframe indicates which components to place on the InvoiceViewerForm and how to configure them.

Conventions:

  • Solid border = visible on load. Dashed border = hidden on load (visible = False).
  • Each component displays: component_name (Type) "fixed text if set at design time".
  • Action buttons are shown/hidden based on invoice status.
  • This form reads globals.current_invoice. If None, redirect to InvoiceListForm.
