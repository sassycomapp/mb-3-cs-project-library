Wireframe: InvoiceEditorForm

Package: invoices/ [Phase 2]

Purpose: Create or edit invoices. Supports create (new invoice) and edit (draft invoices only) workflows.

Source of authority: scaffold-spec.md, DESIGN.md InvoiceEditorForm Scope section, globals-contract.md

Section 1 — Introduction

To the developer: This wireframe indicates which components to place on the InvoiceEditorForm and how to configure them.

Conventions:

  • Solid border = visible on load. Dashed border = hidden on load (visible = False).
  • Each component displays: component_name (Type) "fixed text if set at design time".
  • This form supports both create and edit workflows. Edit mode is only available for draft invoices.
