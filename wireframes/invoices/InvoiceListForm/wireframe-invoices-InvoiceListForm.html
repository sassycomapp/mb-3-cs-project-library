Wireframe: InvoiceListForm

Package: invoices/ [Phase 2]

Purpose: List view of all invoices with search, filter, and row actions. Provides invoice discovery and status awareness.

Source of authority: scaffold-spec.md, DESIGN.md InvoiceListForm Scope section

Section 1 — Introduction

To the developer: This wireframe indicates which components to place on the InvoiceListForm and how to configure them.

Conventions:

  • Solid border = visible on load. Dashed border = hidden on load (visible = False).
  • Each component displays: component_name (Type) "fixed text if set at design time".
  • This form displays invoices in a DataGrid with search and status filter.

Note: Status filter items are populated programmatically: ["All Statuses", "Draft", "Sent", "Paid", "Overdue", "Cancelled"]. Row actions are status-dependent: View (all statuses), Edit (Draft only). Status badges use color-coded backgrounds per DESIGN.md: Draft (grey), Sent (blue), Paid (green), Overdue (red), Cancelled (grey strikethrough). The empty state is shown when the invoice table has no rows for this client instance.
