Implementation Notes

TimeLapseCarouselComponent is a shared custom component used in HomePage and ServicesForm.
Auto-rotates every 5 seconds. Pauses on hover.
Manual navigation via arrow buttons and dot indicators.
Slides are populated from the `services` table.
Responsive: shows 1 slide on mobile, 2-3 on desktop.
Keyboard accessible: arrow keys navigate between slides.
Properties table
None — slides are populated programmatically from the services table.
