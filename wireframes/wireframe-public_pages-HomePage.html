Homepage Template Variants

Classic (default): Hero → Intro → Services → Video → Testimonials → Trust strip → CTA band → Footer
Services: Hero (shorter) → Services → Trust strip → Testimonials → Intro → CTA → Video → Footer
Booking: Hero (strong CTA) → CTA band → Trust strip → Services → Testimonials → Video → Intro → Footer
Minimalist: Hero (concise) → Intro (brief) → Trust strip → CTA band → Footer

All four templates use the same component inventory. Templates differ only by layout, section ordering, and emphasis.
Video section is controlled by business_profile.home_video_url — hidden automatically when no URL is configured.
Properties table
None — all component properties can be set programmatically in code.
