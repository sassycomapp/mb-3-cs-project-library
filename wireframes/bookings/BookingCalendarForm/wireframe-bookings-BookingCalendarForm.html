Wireframe: BookingCalendarForm

Package: bookings/ [Phase 2]

Purpose: Calendar view of bookings with month, week, and day views. Uses 4 template subforms for event rendering.

Source of authority: scaffold-spec.md, build-plan.md Stage 2.3, DESIGN.md Booking Calendar Architecture section

Section 1 — Introduction

To the developer: This wireframe indicates which components to place on the BookingCalendarForm and how to configure them.

Conventions:

  • Solid border = visible on load. Dashed border = hidden on load (visible = False).
  • Each component displays: component_name (Type) "fixed text if set at design time".
  • Calendar event color coding: Confirmed = #388e3c (green), Pending = #f9a825 (yellow), Cancelled = #c62828 (red, 0.6 opacity).
  • View toggle uses SegmentedButton (Month/Week/Day). The active view's panel is visible; others are hidden.

Note: The three view panels (col_month_view, col_week_view, col_day_view) are toggled programmatically based on the active view selection. Only one is visible at a time.
