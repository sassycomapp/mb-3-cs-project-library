Wireframe: tmpl_day_event

Package: bookings/BookingCalendarForm/ [Phase 2]

Purpose: Template subform for rendering a single booking event card in the day view of the booking calendar.

Source of authority: DESIGN.md Booking Calendar Architecture section

Section 1 — Introduction

To the developer: This wireframe indicates which components to place on the tmpl_day_event template subform. This template is used inside a RepeatingPanel in the day view of BookingCalendarForm.

Conventions:

  • Solid border = visible on load. Dashed border = hidden on load (visible = False).
  • Each component displays: component_name (Type) "fixed text if set at design time".
  • Event card has a 4px left border color-coded by booking status: Confirmed = #388e3c, Pending = #f9a825, Cancelled = #c62828 (0.6 opacity).
  • Card has 8px border-radius and subtle shadow. Clickable — opens BookingViewerForm.
