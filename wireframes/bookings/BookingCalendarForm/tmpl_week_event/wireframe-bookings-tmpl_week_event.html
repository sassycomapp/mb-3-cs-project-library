Wireframe: tmpl_week_event

Package: bookings/BookingCalendarForm/ [Phase 2]

Purpose: Template subform for rendering a booking event block in the week view of the booking calendar.

Source of authority: DESIGN.md Booking Calendar Architecture section

Section 1 — Introduction

To the developer: This wireframe indicates which components to place on the tmpl_week_event template subform. This template is used inside a RepeatingPanel in the week view of BookingCalendarForm.

Conventions:

  • Solid border = visible on load. Dashed border = hidden on load (visible = False).
  • Each component displays: component_name (Type) "fixed text if set at design time".
  • Event block has a 4px left border color-coded by booking status. Cancelled events have opacity: 0.5.
