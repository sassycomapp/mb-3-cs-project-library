Wireframe: tmpl_month_day_cell

Package: bookings/BookingCalendarForm/ [Phase 2]

Purpose: Template subform for rendering a single day cell in the month view grid of the booking calendar.

Source of authority: DESIGN.md Booking Calendar Architecture section

Section 1 — Introduction

To the developer: This wireframe indicates which components to place on the tmpl_month_day_cell template subform. This template is used inside a grid layout in the month view of BookingCalendarForm.

Conventions:

  • Solid border = visible on load. Dashed border = hidden on load (visible = False).
  • Each component displays: component_name (Type) "fixed text if set at design time".
  • Today cell: primary-container background. Other-month cells: opacity: 0.4.
  • Event chips use 9px font with status color coding.

Section 3 — Properties Table

ComponentTypeDesigner Property
No Designer-only properties. Day number and event chips are set programmatically.

Programmatic behaviour:

  • Today cell: background set to var(--primary-container).
  • Other-month cells: opacity: 0.4.
  • Event chips: 9px font, left border color from status (Confirmed=#388e3c, Pending=#f9a825, Cancelled=#c62828).
  • Day cell click: navigates to day view for that date.
  • Event chip click: opens BookingViewerForm with globals.current_booking set.
