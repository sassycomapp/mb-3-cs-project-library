Wireframe: AvailabilitySettingsForm

Package: bookings/ [Phase 2]

Purpose: Configure provider availability schedules, blocked dates, buffer time, and advance booking window.

Source of authority: scaffold-spec.md, build-plan.md Stage 2.2, DESIGN.md

Section 1 — Introduction

To the developer: This wireframe indicates which components to place on the AvailabilitySettingsForm and how to configure them.

Conventions:

  • Solid border = visible on load. Dashed border = hidden on load (visible = False).
  • Each component displays: component_name (Type) "fixed text if set at design time".
  • All inputs use role='outlined'.
  • One filled button per screen (primary action), outlined (secondary), text (tertiary).
