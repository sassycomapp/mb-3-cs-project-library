Wireframe: BookingListForm

Package: bookings/ [Phase 2]

Purpose: List view of all bookings with search, filter, and row actions. Toggles to calendar view.

Source of authority: scaffold-spec.md, build-plan.md Stage 2.3, DESIGN.md BookingListForm Columns section

Section 1 — Introduction

To the developer: This wireframe indicates which components to place on the BookingListForm and how to configure them.

Conventions:

  • Solid border = visible on load. Dashed border = hidden on load (visible = False).
  • Each component displays: component_name (Type) "fixed text if set at design time".
  • One filled button per screen (primary action), outlined (secondary), text (tertiary).
