Wireframe: BookingListForm-RowTemplate

Package: bookings/BookingListForm/ [Phase 2]

Purpose: Row template for the BookingListForm DataGrid. Defines the visual structure of each booking row.

Source of authority: DESIGN.md BookingListForm Columns section

Section 1 — Introduction

To the developer: This wireframe indicates which components to place in each row of the BookingListForm DataGrid.

Conventions:

  • Each component displays: component_name (Type) "fixed text if set at design time".
  • Status badge uses color-coded background and text per booking status lifecycle.
  • Edit and Delete icon buttons are visible only for Pending status bookings.

Section 3 — Properties Table

ComponentTypeDesigner Property
No Designer-only properties. All values are set programmatically from the bookings table row.

Programmatic behaviour:

  • Status badge: background and text color from status lifecycle (Confirmed=#d4edda/#155724, Pending=#fff3cd/#856404, Cancelled=#f8d7da/#721c24).
  • Edit button: visible only when status = "pending".
  • Delete button: visible only when status = "pending".
  • View button: visible for all statuses. Opens BookingViewerForm with globals.current_booking set.
  • Edit button: opens BookingEditorForm in edit mode.
  • Delete button: confirmation dialog, then deletes booking.
