Programmatic Properties

PropertyTypeDescription
metric_labelstringKPI name (e.g. "Revenue This Month")
metric_valuestringFormatted value (e.g. "R 24,500")
metric_trendstringTrend text (e.g. "12% vs last month")
metric_trend_directionstring"up" or "down" — controls color and arrow icon
metric_trend_visibleboolShow/hide trend indicator

Implementation Notes

MetricCard is a dashboard-specific subcomponent, not a shared custom component.
Belongs to `dashboard/components/` package.
Used in DashboardForm and DashboardAnalyticsForm.
All 5 properties are set programmatically — no Designer-only properties.
Responsive: card width adapts to container. On mobile, cards stack vertically.
Properties table
None — all component properties can be set programmatically in code.
