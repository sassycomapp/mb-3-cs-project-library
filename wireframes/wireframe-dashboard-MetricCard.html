Dashboard-specific subcomponent. Used inside DashboardForm to display a single KPI metric. Not a shared custom component — belongs to the dashboard/components/ package.

Programmatic properties (set in host form code):
• metric_label — string — The KPI label (e.g., "Revenue This Month")
• metric_value — string — The formatted KPI value (e.g., "R 12,450")
• metric_trend — string — Trend description (e.g., "12% from last month")
• metric_trend_direction — string — "up" or "down" (controls CSS class)
• metric_trend_visible — bool — Whether to show the trend indicator
