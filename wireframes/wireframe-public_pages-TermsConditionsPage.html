Implementation Notes

Reads clauses from the `t_and_c` table. Only active clauses (`is_active = True`) are displayed.
Clauses are ordered by `sort_order` and grouped by `category`.
Seeded clauses are provided by the master template. Custom clauses are added by the Owner via the Policy Editor in Settings.
Shares layout and styling with the Privacy Policy page where appropriate.
The page uses the standard public page layout with FooterComponent.
Properties table
None — all component properties can be set programmatically in code.
