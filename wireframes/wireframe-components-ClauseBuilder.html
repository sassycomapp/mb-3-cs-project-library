Implementation Notes

ClauseBuilder is a shared custom component used by PolicyEditorForm.
Parameterized by document type (`privacy_policy` or `t_and_c`).
Seeded clauses (green border) are non-deletable but editable. Custom clauses (blue border) are editable and deletable.
On save: writes changes to the appropriate data table (`privacy_policy` or `t_and_c`).
See ADR-018 for architecture details.
