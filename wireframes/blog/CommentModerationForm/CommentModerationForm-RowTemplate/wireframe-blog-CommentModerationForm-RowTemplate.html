Wireframe: CommentModerationForm-RowTemplate

Package: blog/CommentModerationForm/ [Phase 4]

Purpose: Row template for the CommentModerationForm DataGrid (dg_comments). Defines the visual structure of each comment row in the moderation list.

Source of authority: blog_comments schema (authoritative-schema.md), screen-blog-CommentModerationForm.html, build-plan.md Stage 4.1

Section 1 — Introduction

To the developer: This wireframe indicates which components to place in each row of the CommentModerationForm DataGrid.

Conventions:

  • Each component displays: component_name (Type) "fixed text if set at design time".
  • This is a DataRowPanel-based template — each component occupies one column slot in the DataGrid.
  • Action button visibility is conditional on comment status (see Programmatic behaviour below).
