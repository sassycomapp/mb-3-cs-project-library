Wireframe: LandingPage

Package: landing_pages/ [Phase 3]

Purpose: Public-facing landing page with 3 template variants (Lead Capture, Event Registration, VSL). Template-specific content panels are toggled by template_type.

Solid border = visible on load Dashed border = hidden on load (visible = False)
Each component shows: component_name (Type) "fixed text if set at design time"
All other properties (role, placeholder, items, etc.) are in the Properties Table only.

Section 1 — Introduction

To the developer: This wireframe indicates which components to place on the LandingPage form and how to configure them.

Conventions:

  • Solid border = visible on load. Dashed border = hidden on load (visible = False).
  • Each component displays: component_name (Type) "fixed text if set at design time".
  • Template-specific content panels are toggled by template_type field.
