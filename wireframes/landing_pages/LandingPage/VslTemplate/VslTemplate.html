Wireframe: VslTemplate

Package: landing_pages/LandingPage/ [Phase 3]

Purpose: Video sales letter landing page template. Best for high-ticket offers and video-driven sales. Built as a content panel inside LandingPage, toggled by template_type = "vsl".

Solid border = visible on load Dashed border = hidden on load (visible = False)
Each component shows: component_name (Type) "fixed text if set at design time"
All other properties (role, placeholder, items, etc.) are in the Properties Table only.

Section 1 — Introduction

To the developer: This wireframe indicates which components to place on the VslTemplate content panel and how to configure them.

Conventions:

  • Solid border = visible on load. Dashed border = hidden on load (visible = False).
  • Each component displays: component_name (Type) "fixed text if set at design time".
  • This template is embedded inside LandingPage and toggled by template_type.
