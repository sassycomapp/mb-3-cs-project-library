Section 1 — Introduction

To the developer: This wireframe indicates which components to place on the ActivityFeed component and how to configure them.

Conventions:

  • Solid border = visible on load. Dashed border = hidden on load (visible = False).
  • Each component displays: component_name (Type) "fixed text if set at design time".
  • This is a data-driven component that displays recent activity from bookings, payments, contacts, and emails.
