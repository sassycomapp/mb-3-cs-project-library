Properties table

rp_activityRepeatingPanelitem_template with icon, title, desc, time
Programmatic properties (set in host form code):
• activity_items — list — Activity records from activity_log table
• max_items — int — Maximum items to display (default: 5)
• view_all_handler — callable — Handler for "View All" link click

Activity item structure:
• action_type — string — Determines icon (e.g., "booking_created", "payment_received")
• description — string — Human-readable activity description
• metadata — object — Additional context (e.g., contact name, amount)
• created_at — datetime — Timestamp (displayed as relative time)
