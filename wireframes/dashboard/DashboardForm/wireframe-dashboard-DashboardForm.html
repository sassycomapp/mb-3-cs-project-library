Package: dashboard/ [Phase 1]

Purpose: Main admin dashboard with metric cards, recent bookings, and activity feed.

Source of authority: scaffold-spec.md, build-plan.md Stage 1.3, DESIGN.md Component and Role Map

Section 1 — Introduction

To the developer: This wireframe indicates which components to place on the DashboardForm and how to configure them.

Conventions:

  • Solid border = visible on load. Dashed border = hidden on load (visible = False).
  • Each component displays: component_name (Type) "fixed text if set at design time".
  • MetricCard components are used for KPI display. ActivityFeed component shows recent business activity.

Section 3 — Properties Table

ComponentTypeDesigner Property
No Designer-only properties. All metric values and data are set programmatically from the business data tables.

Note: MetricCard components display KPI values (revenue, bookings, customers, avg order value). The ActivityFeed component is embedded in the activity card. The empty state is shown when the business has no data yet (onboarding incomplete or no transactions).
