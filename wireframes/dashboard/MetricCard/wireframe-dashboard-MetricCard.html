Wireframe: MetricCard

Package: dashboard/ [Phase 1]

Purpose: Reusable KPI card component for displaying key business metrics on the dashboard.

Source of authority: scaffold-spec.md, DESIGN.md Component and Role Map (metric-card role)

Section 1 — Introduction

To the developer: This wireframe indicates which components to place on the MetricCard component and how to configure them.

Conventions:

  • Solid border = visible on load. Dashed border = hidden on load (visible = False).
  • Each component displays: component_name (Type) "fixed text if set at design time".
  • This is a reusable component used for KPI display on the dashboard.
