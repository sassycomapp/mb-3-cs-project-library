Supported Error Types

404 — Not Found: Code="404", Heading="Page Not Found", Message="The page you're looking for doesn't exist or has been moved."
500 — Server Error: Code="500", Heading="Something Went Wrong", Message="An unexpected error occurred. Please try again or contact support."
403 — Forbidden: Code="403", Heading="Access Denied", Message="You don't have permission to access this page."

Usage

ErrorLayout has NO app bar and NO sidebar. It is a full-viewport centred layout for error and exception presentation.
The error code, heading, message, and button text are set programmatically based on the error type.
The "Go Home" button navigates to homepage (unauthenticated) or Dashboard (authenticated).
All four elements (code, heading, message, button) are dynamic — set by code, not Designer.

Responsiveness

Full-viewport centred layout. Max-width container (480px) ensures readability at all breakpoints.
Text and spacing adapt naturally. No sidebar or navigation chrome to collapse.
Properties table
None — all component properties (role, text, visible, items, event bindings, layout) can be set programmatically in code.
