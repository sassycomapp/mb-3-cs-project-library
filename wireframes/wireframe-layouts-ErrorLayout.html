ErrorLayout

Error and exception presentation layout — no chrome, no sidebar. Centred content with error code, heading, message, and recovery action.

Structure

layout_root (ColumnPanel)
error_container (ColumnPanel)
404
txt_error_code (Label) dynamic — "404", "500", etc.
Page Not Found
hdg_error_title (Heading) "Page Not Found"
The page you're looking for doesn't exist or has been moved.
txt_error_message (Text) dynamic — contextual error description
Go Home
btn_go_home (Button) "Go Home" — appearance: filled

Properties

Designer-Only Properties
None — all component properties (role, text, visible, items, event bindings, layout) can be set programmatically in code.

Usage

ErrorLayout has no app bar and no sidebar. It is a full-viewport centred layout for error and exception presentation.
The error code, heading, message, and button text are set programmatically based on the error type (404, 500, 403, etc.).
The "Go Home" button navigates to the homepage or dashboard depending on authentication state.

Responsiveness

Full-viewport centred layout. Max-width container (480px) ensures readability at all breakpoints.
Text and spacing adapt naturally. No sidebar or navigation chrome to collapse.
