Properties

Designer-Only Properties
None — all component properties can be set programmatically. Clause content is rendered dynamically from the privacy_policy table. Only active clauses (is_active = True) are displayed. Clauses are grouped by category and ordered by sort_order within each category. Clause data is managed via ClauseBuilder in Settings (PolicyEditorForm).

Architecture

Data source: privacy_policy table (authoritative-schema.md §5A.1)
Clause management: ClauseBuilder custom component in PolicyEditorForm (settings/ package)
ADR: 018-legal-policy-responsibility-acknowledgement-and-clause-builder-architecture.md
Layout: Uses FooterComponent. Standard public page layout.
Routing: /privacy via Anvil Routing dependency
Visibility: Only is_active = True clauses rendered
