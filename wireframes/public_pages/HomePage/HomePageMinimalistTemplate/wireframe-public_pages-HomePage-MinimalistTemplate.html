HomePageMinimalistTemplate

Clean, minimal homepage template — light content, generous whitespace, single strong CTA.

Section 1 — Introduction

To the developer: This wireframe shows the Minimalist template variant of HomePage. It is built as a content panel inside HomePage, selected by business_profile.homepage_template = "minimalist". Section order: Hero (concise) → Intro (very brief) → Trust strip (compact) → CTA band → Footer. Hides: carousel, full services grid, full testimonials, video.

Conventions: Solid border = visible on load. Dashed border = hidden on load. Each component shows: component_name (Type) "fixed text"
