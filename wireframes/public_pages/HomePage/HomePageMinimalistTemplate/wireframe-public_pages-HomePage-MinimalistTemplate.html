HomePage — Minimalist Template

Clean, minimal homepage template — light content, generous whitespace, single strong CTA. Public visitor view.

Template: Minimalist

Section order: Hero (concise) → Intro (very brief) → Trust strip (compact) → CTA band → Footer. Hides: carousel, full services grid, full testimonials, video. Uses fewer text blocks and more whitespace.

Visibility Matrix

Visible: Hero, Intro (brief), Trust strip (compact), CTA band, Footer
Hidden by default: TimeLapseCarousel, full services grid, full testimonials section, VideoDisplayComponent (even if URL is set)
