HomePageBookingTemplate

Conversion-focused homepage template — maximises booking and enquiry. CTA appears twice near top.

Section 1 — Introduction

To the developer: This wireframe shows the Booking template variant of HomePage. It is built as a content panel inside HomePage, selected by business_profile.homepage_template = "booking". Section order: Hero (strong booking CTA) → CTA band → Trust strip → Services → Testimonials → Video → Intro → Footer.

Conventions: Solid border = visible on load. Dashed border = hidden on load. Each component shows: component_name (Type) "fixed text"
