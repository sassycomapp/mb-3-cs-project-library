Properties

Designer-Only Properties
None — all component properties can be set programmatically. Template variant selected by business_profile.homepage_template field. Section order and visibility are controlled programmatically per template variant.

Architecture

Form: Single HomePage form with four template variants (Classic, Services, Booking, Minimalist)
Template selection: business_profile.homepage_template field ("classic", "services", "booking", "minimalist")
Shared sections: Hero, Services, Intro, Video, Testimonials, Trust strip, CTA band, Footer — all templates use the same component inventory
Custom components: ParallaxComponent (hero), TimeLapseCarouselComponent (services), VideoDisplayComponent (video), FooterComponent (footer)
Video visibility: Hidden when business_profile.home_video_url is empty
Routing: / via Anvil Routing dependency
Configuration: config table with key = 'home_config' for section settings
User flow: §10 Homepage Customisation
