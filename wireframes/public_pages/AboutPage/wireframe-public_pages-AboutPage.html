AboutPage

Public-facing about page — displays business information, values, and accreditations

Section 1 — Introduction

To the developer: This wireframe indicates which components to place on the AboutPage form and how to configure them. AboutPage is a public-facing read-only page rendered from business_profile table data.

Conventions: Solid border = visible on load. Dashed border = hidden on load. Each component shows: component_name (Type) "fixed text"
