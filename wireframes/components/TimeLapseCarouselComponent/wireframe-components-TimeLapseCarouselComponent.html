Section 1 — Introduction

To the developer: This wireframe indicates which components to place on the TimeLapseCarouselComponent and how to configure them.

Conventions:

  • Solid border = visible on load. Dashed border = hidden on load (visible = False).
  • Each component displays: component_name (Type) "fixed text if set at design time".
  • This is a shared custom component for auto-rotating image carousels.

Section 3 — Properties Table

ComponentTypeDesigner Property
No Designer-only properties. All component properties (images, rotation interval, navigation) are set programmatically in code.

Note: Slide images are populated from the host form's data source. The carousel auto-rotates at a configurable interval. Dot indicators reflect the current slide. Previous/Next buttons allow manual navigation.
