Section 1 — Introduction

To the developer: This wireframe indicates which components to place on the ParallaxComponent and how to configure them.

Conventions:

  • Solid border = visible on load. Dashed border = hidden on load (visible = False).
  • Each component displays: component_name (Type) "fixed text if set at design time".
  • This is a shared custom component for parallax scroll effects on public pages.

Section 3 — Properties Table

ComponentTypeDesigner Property
No Designer-only properties. All component properties (image source, headline text, body text, button text) are set programmatically in code.

Note: The background image uses a fixed-position CSS effect to create the parallax scroll illusion. Headline, body text, and CTA button text are set by the host form. The component accepts image_url, headline, body_text, and cta_text as constructor parameters.
