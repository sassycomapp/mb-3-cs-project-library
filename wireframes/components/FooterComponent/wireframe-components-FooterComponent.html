Wireframe: FooterComponent

Package: components/ [Phase 4]

Purpose: Shared footer component used on all public pages (HomePage, AboutPage, ContactPage, PrivacyPolicyPage, TermsConditionsPage, LandingPage).

Source of authority: DESIGN.md Custom Components Inventory, scaffold-spec.md

Section 1 — Introduction

To the developer: This wireframe indicates which components to place on the FooterComponent and how to configure them.

Conventions:

  • Solid border = visible on load. Dashed border = hidden on load (visible = False).
  • Each component displays: component_name (Type) "fixed text if set at design time".
  • This is a shared custom component used on all public-facing pages.
