Architecture note: This is a display-only component. It renders a video embed when a valid video URL is provided. Input controls (source selector, URL field) belong in the host forms — BlogEditorForm, ServiceEditorForm, and SettingsForm. The component receives video_url and video_type as properties set programmatically by the host form. Visibility is programmatic: if video_url is empty or invalid, the host form sets visible = False. V1 supports YouTube only. Multi-source support (Vimeo, Dailymotion, custom) is deferred to V2.

Programmatic properties (set in host form code, not Designer):
video_url — string — The YouTube URL to embed
video_type — string — Video source type (V1: "youtube" only)
video_caption — string — Optional caption text below the video
visible — bool — Set to True if video_url is valid, False otherwise

Host form responsibilities:
1. Set video_url and video_type from the data source
2. Validate the URL before setting visible = True
3. Optionally set video_caption for descriptive text below the video
