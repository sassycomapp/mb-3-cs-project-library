Wireframe: ClauseBuilder

Package: components/ [Phase 4]

Purpose: Shared custom component for editing legal policy clauses (privacy_policy or t_and_c). Parameterised by document_type.

Source of authority: DESIGN.md ClauseBuilder section, scaffold-spec.md, ADR-018

Section 1 — Introduction

To the developer: This wireframe indicates which components to place on the ClauseBuilder custom component and how to configure them.

Conventions:

  • Solid border = visible on load. Dashed border = hidden on load (visible = False).
  • Each component displays: component_name (Type) "fixed text if set at design time".
  • This is a shared custom component parameterised by document_type ("privacy_policy" or "t_and_c").
  • Green dashed border = component boundary.
