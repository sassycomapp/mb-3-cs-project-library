Implementation Notes

ParallaxComponent is a shared custom component used in HomePage, AboutPage, and LandingPage.
Creates a full-width hero section with parallax scroll effect.
Background image is configurable via `business_profile.hero_image_url` or page-specific content.
Title, subtitle, and CTA buttons are dynamic — set by the host page.
Parallax effect is achieved via CSS `background-attachment: fixed` or JavaScript scroll listener.
Fallback behavior when `prefers-reduced-motion: reduce` — static background, no parallax.
Mobile behavior: parallax disabled on mobile (static background), content stacks vertically.
Properties table
None — all properties are set programmatically from the host page.
