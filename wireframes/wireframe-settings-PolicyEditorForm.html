Implementation Notes

The PolicyEditorForm is accessed from Settings → Website.
It uses the ClauseBuilder shared custom component, parameterized by document type (`privacy_policy` or `t_and_c`).
Seeded clauses (green border) are non-deletable but editable. Custom clauses (blue border) are editable and deletable.
Publish writes to the corresponding data table and updates the public page.
See ADR-018 for architecture details.
