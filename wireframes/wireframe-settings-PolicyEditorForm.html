Behaviour Notes

Component Behaviour
1. Document Type Selection: When the Owner selects a document type from dd_document_type, the ClauseBuilder loads clauses from the corresponding data table (privacy_policy or t_and_c).

2. Category Filtering: The dd_category_filter dropdown filters clauses by category within the selected document type.

3. Seeded Clauses: Clauses from the master template (is_seeded = True) are displayed with a green left border. The Owner can edit their text but cannot delete them.

4. Custom Clauses: Clauses added by the Owner (is_seeded = False) are displayed with a blue left border. The Owner can edit and delete them.

5. Add/Edit Clause: Clicking "+ Add Custom Clause" or "Edit" reveals the clause form. The Owner enters/edits title and body text, then clicks "Save Clause".

6. Publish: Clicking "Publish" writes all changes to the appropriate datatable and publishes the updated content to the public-facing policy page. Version history is updated.

7. Version History: After publishing, the version history panel shows previous versions with timestamps. Each version can be viewed.

8. ADR Compliance: This screen implements the clause-builder architecture from `18-legal-policy-responsibility-acknowledgement-and-clause-builder-architecture.md`. The Owner is solely responsible for policy content. Mybizz provides the tool but not the content.
