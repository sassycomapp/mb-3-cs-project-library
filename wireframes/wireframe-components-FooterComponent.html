Implementation Notes

FooterComponent is a shared custom component used on all public pages.
Logo, social links, and contact details are pulled from `business_profile` table.
Privacy Policy and Terms & Conditions links navigate to the corresponding public pages.
The footer uses the standard M3 surface-container-low background.
Responsive: columns stack vertically on mobile.
Properties table
None — all component properties can be set programmatically from business_profile data.
