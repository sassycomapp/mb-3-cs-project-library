Usage

BlankLayout is the shell for all public-facing pages.
It provides a simple header with business name, navigation links, and a "Book Now" CTA button.
Content loads into the content_area ColumnPanel via Anvil Routing.
No sidebar, no admin navigation — clean public-facing layout.
The FooterComponent is added inside each public page, not in the layout.
Properties table
None — all component properties can be set programmatically in code.
