Calendar Template Subforms

tmpl_day_event: Event card with 4px left border (color-coded by status), 8px border-radius, subtle shadow. Shows: event title, time range, description, status badge.
tmpl_month_day_cell: Day cell in month grid. Today cell has primary-container background. Other-month cells have opacity 0.4.
tmpl_week_event: Event block in week view with left border color coding.
tmpl_week_timeslot: Time row: 60px time label column + 1fr content. Empty timeslots show thin spacer line.

Event color coding:
Confirmed: border #388e3c (green)
Pending: border #f9a825 (yellow)
Cancelled: border #c62828 (red), opacity 0.6
