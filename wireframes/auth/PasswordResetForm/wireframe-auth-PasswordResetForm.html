PasswordResetForm — Wireframe

This wireframe defines the component structure for the PasswordResetForm in the auth package. It is an instructive document, not a visual design. Use it to identify which M3 components to place on the form and how they should be configured.

Conventions used in Section 2:
• Solid border = component is visible on load.
• Dashed border = component is hidden on load (visible = False).
• Each component annotation shows: component_name (Type) "fixed text".
• Container components show their children indented inside.
• (W) = Write Back must be enabled in Designer Data Bindings panel.

Wireframe Diagram

card_password_reset (Card) [outlined]
hdg_reset_title (Heading) "Reset your password"
txt_reset_subtitle (Text) "Enter your email address and we'll send you a link to reset your password"
txt_reset_error (Text) [error message — hidden on load]
txt_reset_success (Text) [success message — hidden on load]
txt_email (TextBox) (W) appearance="outlined" placeholder="Email address"
btn_send_reset (Button) "Send Reset Link" appearance="filled"
nav_back_to_login (Link) "Back to log in"
