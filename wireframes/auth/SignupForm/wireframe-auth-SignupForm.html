SignupForm — Wireframe

This wireframe defines the component structure for the SignupForm in the auth package. It is an instructive document, not a visual design. Use it to identify which M3 components to place on the form and how they should be configured.

Conventions used in Section 2:
• Solid border = component is visible on load.
• Dashed border = component is hidden on load (visible = False).
• Each component annotation shows: component_name (Type) "fixed text".
• Container components show their children indented inside.
• (W) = Write Back must be enabled in Designer Data Bindings panel.
• hide_text = Password masking must be set in Designer.
