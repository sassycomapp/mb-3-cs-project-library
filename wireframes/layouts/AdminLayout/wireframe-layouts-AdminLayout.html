Properties

Designer-Only Properties
None — all component properties (role, text, visible, items, event bindings, layout) can be set programmatically in code.

Navigation Architecture

Sidebar navigation uses plain Link components with lambda click handlers. NavigationLink and navigate_to are not used. Conditional visibility: Campaigns, Broadcasts, Segments, Tasks (marketing_enabled); Blog (blog_enabled); Vault (owner only). Sign Out is always visible at sidebar bottom for all roles.

Responsiveness

Desktop (≥998px): Fixed sidebar (260px) + content fills remainder.
Mobile (<998px): Sidebar collapses to hamburger drawer overlay. Content is full-width.
