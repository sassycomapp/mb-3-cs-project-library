Wireframe: ErrorLayout

Package: layouts/ [Phase 1]

Purpose: Application-level error and exception presentation (404, 500, 403, etc.). Full-viewport centred layout with NO chrome — no app bar, no sidebar, no navigation.

To the developer: This wireframe indicates which components to place on the ErrorLayout and how to configure them.

Conventions:

  • Solid border = visible on load. Dashed border = hidden on load (visible = False).
  • Each component displays: component_name (Type) "fixed text if set at design time".
