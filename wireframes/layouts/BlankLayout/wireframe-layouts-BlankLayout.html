Designer-Only Properties
None — all component properties (role, text, visible, items, event bindings, layout) can be set programmatically in code.

Usage

BlankLayout is the minimal chrome wrapper. It provides an app bar with page title, notification, and user menu — but no sidebar navigation.
Used for: onboarding, authentication flows, standalone settings sub-forms, and focused content screens that do not require persistent navigation.

Responsiveness

Full-width at all breakpoints. No sidebar to collapse. Content area adapts naturally to viewport width.
