Properties table
All footer content is rendered programmatically from the business_profile table. No designer-only required properties. The component constructor accepts no parameters — it reads directly from the current user's business_profile row. Social links open in new tabs. "View on Google Maps" opens the URL from business_profile.google_maps_embed_url. "Send us a message" navigates to the ContactPage form.

--- ### Responsive Behaviour | Width | Layout | |---|---| | ≥ 768px (desktop) | flow_top: two columns (logo + name | accreditations). flow_middle: two columns (social + legal links | contact + map). flow_copyright: side-by-side copyright and back-to-top. | | < 768px (mobile) | flow_top: single column, stacked. flow_middle: single column, stacked — social links first, contact info below. flow_copyright: stacked — copyright above back-to-top. All flex-wrap enabled. Min-width constraints removed on mobile. | ### Accessibility - All icon buttons have `aria-label` attributes (e.g., "Facebook", "Instagram"). - All links have descriptive text or `aria-label`. - Logo image has `alt` text from `business_profile.business_name`. - "Back to Top" link uses `scrollIntoView()` for smooth scroll. - Footer uses `
` semantic element in implementation. ### Anvil M3 Compliance Notes - All buttons use M3 role-based styling: `icon-button` for social, `nav-item` for links. - Colors use `theme:` prefix — no hardcoded hex. - Spacing follows 4px rhythm. - Typography uses M3 scale: `label-title` (Body Large) for contact info, `caption` for copyright. - Border radius: 100px for icon buttons (pill), 12px for card containers. - Elevation: 0dp (flat surface) — footer is a flat bottom section, not elevated.
