Material 3 Design System with MUI Aesthetic Overlay — Visual Reference for Anvil Implementation

What this file is: A visual demonstration of the current design system as it should look when correctly applied. It is NOT a wireframe, NOT a production UI, and NOT a template to copy structurally. It shows the aesthetic result of applying DESIGN.md, the MUI overlay, the palette tokens, and the screen-production-standard together.
Palette: Professional Blue (default). MUI overlay: 9 aesthetic variables applied. Font: Roboto.

All 9 MUI Aesthetic Variables Demonstrated:
1. Surface distinction: Two-level background (surface) vs panels (surface-container-low).
2. Card shadow: MUI dual-layer hsla(220,30%,5%,0.07) replaces M3 2dp elevation.
3. Card border radius: 8px (was 12px). Buttons, inputs, data grid, dialogs unchanged.
4. Typography heading weight: 600 (was 400) on Headline roles.
5. Dividers: outline-variant at 40% opacity (translucent hairlines).
6. State hover opacity: 0.08 (demonstrated on nav items and buttons).
7. State pressed/focused opacity: 0.12.
8. App bar: Surface token, hairline bottom border (no gradient).
9. Left nav: Surface-container-low background, hairline right border.

11. ErrorLayout

ErrorLayout — Full-viewport centred, no chrome, Display typography
404
Page not found

ErrorLayout specification (from design-remediation-report-2026-06-16):
Full-viewport centred layout, no chrome (no sidebar, no app bar).
Error code in Display type (57px). Heading in Headline Large (32px, weight 600 per MUI).
Message in Body Large (16px). Max-width container: 480px.
Single "Go Home" filled button. Navigates based on auth state.
Supports 404, 500, 403 error types.
